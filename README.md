# Mo Tools 🚀

**موقع ادوات مفيدة للمطورين** - من **Mohammed Hussein / [iegy.net](https://iegy.net)**

## 📌 وصف المشروع

Mo Tools هو موقع ويب يقدم مجموعة من الأدوات المفيدة للمطورين، مثل:
- 📄 **مستعرض HTML** - كتابة و معاينة كود HTML اونلاين
- 📋 **منسق JSON** - تنسيق و تصحيح كود JSON
- 🔐 **Base64 Encoder/Decoder** - تحويل نص إلى Base64 و العكس
- 🎨 **اختيار الألوان** - اختيار الألوان و الحصول على كود HEX, RGB, HSL
- 💅 **منسق CSS** - تنسيق و تصغير كود CSS

## 🎨 ميزات التصميم

- **تصميم ترمنال من المستقبل** (Neon/Dark Theme)
- **3 ثيمات مختلفة** (Neon Green, Purple Cyber, Blue Ocean)
- **تغيير الثيم** بسهولة من أي صفحة
- **حفظ الثيم المختار** في localStorage
- **تصميم متجاوب** (يعمل على mobile و desktop)
- **تأثيرات خفيفة** للزرار و الإطارات

## 🛠 تقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: localStorage (لحفظ البيانات مؤقتًا)
- **Hosting**: GitHub Pages

## 🔧 ميزات كل أداة

### 1. مستعرض HTML
- كتابة HTML, CSS, JavaScript كامل
- معاينة فورية عند الكتابة
- حفظ الكود في localStorage
- أمثلة جاهزة

### 2. منسق JSON
- تنسيق JSON لقراءته بسهولة
- تصغير JSON (إزالة المسافات)
- التحقق من صحة JSON
- حفظ المدخلات في localStorage

### 3. Base64 Encoder/Decoder
- تشفير نص إلى Base64
- فك تشفير Base64 إلى نص
- تبادل المدخلات و المخرجات
- حفظ المدخلات في localStorage

### 4. اختيار الألوان
- اختيار اللون باستخدام color picker
- إدخال قيم HEX, RGB, HSL يدويًا
- عرض جميع صيغ الألوان (HEX, RGB, HSL)
- توليد ألوان عشوائية
- حفظ تاريخ الألوان المختارة

### 5. منسق CSS
- تنسيق CSS لقراءته بسهولة
- تصغير CSS (إزالة المسافات)
- دعم التعليقات و جميع خصائص CSS
- حفظ المدخلات في localStorage
